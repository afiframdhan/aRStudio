# AR Studio Recording

Professional portfolio + studio website for **AR Studio Recording / Afif Ramdhan**.

## Stack
- **GitHub** — source code/version control
- **Cloudflare Pages** — production hosting and automatic deployment from `main`
- **Supabase** — database, booking, and authentication
- **Google Drive + Apps Script** — optional large media/file upload bridge

## Main website sections
Selected Work, Engineer Profile, Before/After Case Study, Services, Workflow, Testimonials, Pricing, Gallery, Contact & Booking.

## Start here
Read **DEPLOY_CLOUDFLARE.md**, then run **supabase/schema.sql** in Supabase SQL Editor and fill in `config.js`.
