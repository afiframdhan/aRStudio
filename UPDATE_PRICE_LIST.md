# Update Price List
Price List sekarang disimpan di tabel `price_list` pada Supabase, bukan Spreadsheet.

Buka Supabase → Table Editor → `price_list`, lalu edit `service`, `price`, `unit`, `features`, `description`, `details`, `notes`, `active`, dan `sort_order`.
Perubahan konten tampil di website tanpa perlu deploy ulang Cloudflare Pages.
